## 一、AI 与高新技术（8 条）

**1. 乌镇峰会今日开幕 + 国内首份 AI 产业链划分标准实施：OpenRouter 数据显示国产模型周调用量连续 26 周超美国**

事件：2026 年世界互联网大会乌镇峰会 11/2-5 举行，主题「开源开放 共建共享——携手构建网络空间命运共同体」，专设「人工智能乌镇对话」环节（11/3 起分论坛覆盖智能体互信互联、机器人与具身智能、时空智能等）。同期，中国人工智能产业发展联盟（AIIA）提出、中国信通院牵头编制的《人工智能产业链划分指引》（AIIA/T 0346-2026）正式实施——国内第一份系统梳理 AI 全产业链层级的团体标准，把产业划分为能源、数据、算力、模型、应用五层，逐层给出定义、边界与核心指标。数据佐证：全球 AI 模型聚合平台 OpenRouter 显示，10/19-25 当周 DeepSeek V4.1-Flash-1017 单周调用量 33.6 万亿 Token 登顶全球第一，全球前五清一色为中国模型（合计 93.54 万亿 Token，美国模型合计 22.47 万亿），国产模型调用总量已连续 26 周力压美国。

关注原因：产业链标准统一的是各地统计口径——此前招商与资本布局常因口径不一而对不上号；叠加乌镇窗口的开源生态数据，中国 AI 的竞争维度正从「单模型能力」扩展到「标准 + 生态 + 调用量」的系统性输出，这是「开源换生态」策略进入收获期的标志。

**2. DeepSeek Super-agent 架构细节发酵：AI 自己发现仓库 Bug 并提交修复，端到端耗时 15 分钟 vs 传统方案 29 分钟**

事件：10/31 晚 DeepSeek Harness 团队发表《Super-agent 设计探索：迈向更自主的 Agent 系统》：双层架构（Router 主管分派验收 + Worker 工人独立上下文并发执行）、事件驱动、异步多信道交互、存算分离与外部 Watchdog 防卡死，人类角色上移至高层决策与验收。官方数据：端到端耗时压至约 15 分钟（传统方案约 29 分钟），代价是缓存 token 多耗约 37%。基于该思路的内部 Super-agent 实例已持续运行，日常参与问题复现与修复、代码审查响应及 Harness 自身迭代——AI 能自己发现仓库里的 Bug 并直接提交修复。

关注原因：Agent 竞争的主战场已从「单轮对话质量」转向「组织方式与工程化」——人只管说清楚要什么，分派、执行、验收被系统接管。这与海外同期 agent 产品动作同向，也意味着 token 消耗结构与推理算力需求将继续超线性增长。

**3. 可灵 AI 增资 198.02 亿元交割：中东资方临阵退出、金蝶与沐曦接盘，股东名单含阿里腾讯百度**

事件：快手 10/30 晚公告，视频大模型可灵 AI 增资完成交割，实际到账 198.02 亿元（约 29 亿美元），较此前公告的 204.47 亿元上限少 6 亿多——差额来自中东资方旗下两个主体未按期缴款（其中一个 8000 万美元认购义务直接终止），空出份额由金蝶与沐曦数智接盘（均为首次入股）；股东名单中阿里巴巴、腾讯、百度均在。

关注原因：这是视频生成赛道迄今单笔最大融资的落地样本。中东资本退出与 OpenAI 砍融资发生在同一周——AI 一级市场「钱还在、但变挑剔」；可灵按上限完成近 97% 与 OpenAI 估值下调 10.7% 形成的温差说明：有真实收入的应用层与靠长期承诺估值的模型层，正在被区别定价。

**4. 谷歌 TPU 首次在轨推理成功：卫星回传一首俳句，皮查伊称之为「太空里的 Hello World」**

事件：谷歌宣布逐日者计划的原型卫星在轨道上完成一次完整的 AI 推理：地面发指令上去，板载 TPU 通电跑模型，结果传回地球——回来的是一首关于地球的俳句；皮查伊将其称为「太空里的 Hello World」。工程限制仍明显：卫星供电约 1 千瓦，单次工作窗口约 20 分钟，散热紧张。

关注原因：数据中心级芯片第一次在轨道上真正算出东西——太空算力从概念走到工程验证。对卫星遥感、星上自治、天基军事应用是长线变量，也意味着「算力基建」的疆域正式从地面数据中心向外太空延伸。

关注原因：大厂中最后一个未直接下场的字节转向自研，标志具身智能从「demo 竞赛」进入「出货量、收入、数据规模」的产业化验证阶段；而中国供应链（傅利叶-Meta 合作上周刚曝光）在成本与迭代上的优势仍在强化。

**7. Cursor 扩展市场曝投毒事件：官方 Claude Code 插件被替换为恶意包、植入 SSH 长期后门**

事件：本周 Cursor 扩展市场中官方 Claude Code 插件的两个版本被换成恶意包，安装后会偷偷植入一把 SSH 密钥、留下长期后门。Cursor 已于 10/29 发布安全通告，下架相关版本并给出自查步骤；Anthropic 随后表态称这不是自家系统被攻破，更像是有针对性的投毒。

关注原因：AI 编码工具的供应链攻击面（插件市场 + 分发渠道）首次被大规模验证——对企业开发者是立即的自查动作项，也预示「AI 工具链安全」将成为企业采购的新尽职调查维度。

**8. 英伟达 RTX Spark Windows 笔记本开卖；NAACP 诉 xAI 数据中心污染案获准推进**

关注原因：一端是「AI 算力下沉到个人终端」的产品化拐点，一端是 AI 数据中心的环保足迹正式进入司法程序——算力扩张的社会成本（电力、排放、社区影响）开始被系统性计价，类似诉讼可能随算力规模扩大而增多。

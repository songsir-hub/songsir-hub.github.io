名字的来处Where the name comes from

「博雅」二字取自这座个人主页的名字——博雅小筑；而博雅小筑，又得名于澳门大学莲花广场上那座「博雅之璧」。

雕塑由国家教育部赠送给澳门大学，委托中央美术学院组织设计与创作，二〇一八年落成于校园。它承载澳大「仁、义、礼、知、信」的校训，也寄着「大博」「大雅」的育人期许：为学要眼界广博，为人要举止清雅。以这两个字为名，是给自己留一个尺子。

后来做了一款阅读器、又整理出一套随卡分发的有声书网页，都沿用了这个词根。名字是旧的，东西是新的。

两件东西Two things, two jobs

博雅阅读器

Boya Reader

一个不联网的 Android 阅读器。把存储卡里的网页、文本、Word 与 EPUB 变成能读、能听的页面，管的是「怎么读」。

博雅有声书库

Boya Library

随卡分发的网页卡包。音频与逐句文字排在一起，点一句读一句；离开阅读器，用普通浏览器也打得开，管的是「读什么」。

两者共用「博雅」词根，靠后缀区分：一个是运行时，一个是内容。技术形态上仍称 HTML 点读系统，两边靠一份不变的契约对接，各自演进互不牵扯。

    参与与边界Taking part

    建议、报错，或想推荐一份值得做成卡包的公有领域文本，可以到 Issues 留一句，标题写上作品名即可。等基线补齐，这里会按 manifest.json 的字段开放作品提交。

    • 只收自己录的朗读与原创字幕、公有领域文本，以及已明确授权可再分发的内容；第三方教材和原版录音不进这个池子。
    • 每个卡包自带署名与许可说明，改一版升一次版本号。
    • 阅读器不内置内容市场，书库不托管大体积音频；两件东西都不联网、不要账号。
    • 反馈留在可检索的地方，不建群，也不做需要天天照看的渠道。

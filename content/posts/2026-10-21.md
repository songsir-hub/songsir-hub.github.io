## 一、AI 与高新技术（7 条）

**1. 美对华 AI 制裁连升：DHS 禁联邦采购 DeepSeek、美制裁 5 家中企，商务部两度强硬回应**
事件：美国土安全部 10/19 宣布禁止美联邦政府民事行政机构采购中国 AI 企业深度求索（DeepSeek）及其关联企业开发的产品和服务，并要求从相关机构信息系统移除；美方 10/19 还依据《保护美国知识产权法》以"窃取商业秘密"为由对 5 家中国企业实施制裁。商务部 10/20 两度回应：强烈不满、坚决反对，指美方"泛化国家安全概念、将科技经贸问题政治化、工具化"，敦促立即撤销歧视性限制措施，否则将采取必要措施回应。
关注原因：AI 已成中美博弈主战场，限制手段从出口管制延伸到联邦采购排除；国产大模型自主可控与出海逻辑同步强化，关注反制工具与中美 AI 对话机制（约定 11 月底前下次对话）的兜底作用。

**2. MiniMax 发布 M3.1 Flash：提速近 3 倍、成本降 70%，并计划开放权重**
事件：MiniMax 10/20 发布 M3.1 Flash，以稀疏注意力架构实现输出速度超 200 TPS，DeepSWE v1.1 得分 73.7%（GPT-5.6 Sol 为 73.0%）；输入每百万 Token 1 元、输出 4 元，已上线 API 并将开放权重。
关注原因：中国厂商在"速度×成本×开放权重"上持续施压闭源 API 定价；Agent 与端侧场景对低时延、低成本模型需求旺盛，开放权重进一步降低全球开发者采用门槛。

**3. 前 OpenAI CTO 公司开源 975B 参数模型 Inkling，迄今最大美国开放权重模型**
事件：Thinking Machines Lab（Mira Murati 创立）10/20 以 Apache 2.0 许可证在 Hugging Face 发布 9750 亿参数开放权重模型 Inkling，可免费商用与修改。
关注原因：开放权重竞赛从中国主导扩展到美国前沿实验室，基础模型商品化加速，对闭源厂商的定价权与 API 黏性构成长期压力。

**4. OpenAI 三款 Aurora 神秘模型现身 API 后下架；被曝将推 Terra，前沿模型进入"月更"混战**
事件：开发者 10/18 发现 OpenAI API 模型列表出现 aurora-red/green/blue-alpha 三个条目，第三方调用均返回 503 错误后条目消失；The Information 称 OpenAI 计划未来几周推出新一代 Terra 模型，谷歌代号 Gemini 4 Carbon 的新模型也在研发中；过去一个月 OpenAI、Anthropic、谷歌累计发布新模型已超过 12 款。
关注原因：前沿实验室发布节奏本身成为竞争变量，版本迭代加快算力需求与 API 价格波动；关注 10 月底—11 月密集发布对产业链的催化。

**5. 英伟达 NVHBM 倒逼三星、台积电联合开发 3nm 基底芯片**
事件：英伟达下一代 AI 加速器的定制高带宽内存（NVHBM）对制造流程提出统一标准，要求三星、台积电共同参与 3nm 基底芯片开发，美光与 SK 海力士亦被纳入该计划（10/19–20 报道）。
关注原因：AI 芯片竞争从单点算力扩展到"内存—基板—封装"全栈协同；三巨头被同一标准绑定，供应链集中度与议价权格局面临重塑。

**6. 腾讯元宝搜索经腾讯云对外开放：面向大模型与 Agent 的搜索引擎上线**
事件：腾讯 10/20 宣布元宝搜索正式通过腾讯云对外开放，整合全网公开资源与腾讯优质内容，将大模型技术应用于内容收录、理解、检索全链路，构建面向大模型和 Agent 的搜索引擎。
关注原因：搜索是大模型落地的高频入口，"云对外开放"意味着从 C 端产品转向 B 端基础设施；Agent 检索质量直接决定智能体产出，国内云厂商开始卡位。

**7. AI 信用与基建担忧升温：Elice 上市首日暴跌 32%，华尔街封堵第三方 AI 智能体**
事件：韩国数据中心基础设施公司 Elice 10/20 上市首日收跌 32%，为韩国大型 IPO 史上最差首日表现（IPO 募资 2010 亿韩元、散户认购 400 倍）；同日报道，摩根大通等美国大型金融机构正阻止第三方 AI 智能体直接访问客户账户或转移资金，戴蒙称客户授权后须自担责任。
关注原因：一级市场对"AI 基建巨额投资合理性"的定价开始苛刻；金融场景对 Agent 的安全与问责门槛，预示 AI 落地从"能力演示"转向"责任框架"。

事件：欧盟将 2026 年 10 月设为对华经贸"实质成果"截止期，若无成果将更快、更积极地部署约 230 项贸易防御工具（反倾销/反补贴/保障措施）；日经 10/20 报道，到 2028 年前后欧盟最多 334 万辆电动车所需域内电池无法得到供应（欧洲产电池比中国贵约 30%），欧盟要求电池域内生产作为补贴条件但进展不顺；欧盟施压英国对齐对华电动车关税，英商务大臣雷诺兹明确拒绝（英国现维持 10% 标准关税）；中方已就欧盟对华电动汽车措施在 WTO 提起争端解决程序。
关注原因：中欧博弈进入月度节奏，关键矿产、电动车、钢铁、光伏是前沿；欧洲"战略自主"与供应链现实之间的缺口，是中国企业本地化布局（匈牙利建厂、西班牙代工等）的窗口。

**20. 资本市场制度供给加码：违规减持新规 12/1 施行、吴清金融街论坛定调、非银流动性支持工具**

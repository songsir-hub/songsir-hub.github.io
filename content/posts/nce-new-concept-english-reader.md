# 新概念英语点读学习

《新概念英语》（*New Concept English*）全四册在线点读系统，支持课文朗读、单句点读与中英对照，响应式设计，手机、平板、电脑都能流畅使用，无需安装。

{{< figure src="/images/nce-cover.svg" caption="《新概念英语》点读学习界面示意" >}}

## 怎么用

- 打开下方入口，选择一册（1997 版或 1985 版），从第一课开始逐句点读、跟读。
- 点任意一句即可播放该句音频；中英对照逐句显示，便于理解。
- 系统支持「播放 → 暂停 → 单句复读 → 听写」等学习动作，可随时切换课本。

## 学习路径建议

| 册 | 定位 | 课数 | 词汇量 |
|---|---|---|---|
| 第一册 | 语音与基础（零基础） | 144 | 约 600 |
| 第二册 | 语法体系与听说读写 | 96 | 约 1500 |
| 第三册 | 进阶阅读与复杂句型 | 60 | 约 2500 |
| 第四册 | 流利表达与学术阅读 | 48 | 3500–4000 |

推荐按册顺序学习：第一册打基础，第四册冲刺流利。

## 下载单文件与部署（两种方法）

**下载**：[⬇ `nce-single-file.html`](https://songsir-hub.github.io/nce/nce-single-file.html)（单文件 648 KB，不含音频）

这个单文件把全部界面、代码、样式打进一个 HTML，**无需安装**。发给朋友后，任选一种方式使用：

**方法一 · 双击直接打开（最简单，推荐先试）**
1. 用微信 / QQ 把该文件发给朋友（或传到手机 / 电脑）；
2. 电脑**双击**、手机用浏览器（Chrome / Safari）打开；
3. 联网状态下点任意一课，会自动拉取该课音频播放。

> 联网才出声音，断网看不了（要离线用方法二）。

**方法二 · 安装为离线应用 PWA（断网可点读）**
1. 访问在线版 [songsir-hub.github.io/nce/](https://songsir-hub.github.io/nce/)；
2. 浏览器菜单选「**安装应用 / 添加到主屏幕**」（Chrome / Edge 地址栏有安装图标；手机 Safari 用「分享 → 添加到主屏幕」）；
3. 首次安装缓存全部 8 本音频（约 270–380 MB），**之后断网也能点读**。

**两种怎么选**

| | 方法一 双击直开 | 方法二 装 PWA 离线 |
|---|---|---|
| 联网要求 | 联网才出声音 | 装一次后断网可用 |
| 体积 | 648 KB（不含音频） | 首装下 270–380 MB |
| 适合 | 随手发朋友试用 | 长期用、要离线 |

二者互补：**单文件是「轻入口」，PWA 是「离线完整版」**。

**安装环境（哪些设备能装 PWA / 打不开怎么办）**

PWA「安装到桌面」入口只在 **Chrome / Edge / Safari** 上稳定出现，国产定制浏览器和老系统基本看不到：

| 设备 / 系统 | 能不能装 PWA | 建议 |
|---|---|---|
| 安卓 + Chrome / Edge | ✅ 能 | 装 PWA 最稳 |
| iPhone / iPad + Safari | ✅ 能 | 地址栏右侧「⊞ 安装」或「分享 → 添加到主屏幕」 |
| 华为鸿蒙 **4.0+** + 较新浏览器 | ✅ 能（提示隐蔽，藏在「⋮」菜单） | 翻菜单找「安装应用 / 添加至主屏幕」 |
| 华为鸿蒙 **2.0 / 3.x** 老系统 | ❌ 基本不行（浏览器内核太老） | 别装，改用「单文件 + Chrome 打开」联网学 |
| vivo 自带浏览器 / UC / QQ 浏览器 / 360 | ❌ 不支持 / 很弱 | 换成 Chrome 再试，或直接用单文件 |
| 国产平板（华为 / 小米等）装 **Edge** | ❌ 基本不行（商店无官方包 / 侧载功能残缺） | 别走 Edge，用 Chrome 或单文件 |

**一句话**：装 PWA 认准 **Chrome / Edge（新版桌面系统）/ Safari**；老系统、国产平板或国产浏览器装不了，就用**单文件联网学**，够用。

**QQ 里点文件卡在「资源加载中」怎么办**

单文件内联了大段脚本与样式（648 KB），QQ 内置的浏览器解析慢且不稳定，会一直停在「资源加载中」。处理办法：

- 手机 QQ：不要直接在聊天窗点，**长按文件 → 用浏览器打开**（选 Chrome / Safari 即可正常加载）；
- 电脑 QQ：另存到本地，**右键 → 打开方式 → 选 Chrome / Edge**（别用 QQ 自带网页）。

**要不要加收藏夹 / 怎么装**

建议不要只加普通网页收藏——单文件收藏没用（它只是个本地 .html，换个设备就找不到）。想随时打开，按使用方式选：

- 偶尔试读：**把在线版 `songsir-hub.github.io/nce/` 加进浏览器书签**（Chrome/Edge 点地址栏⭐），下次一点就开，联网就能学；
- 长期用、要离线：走方法二把在线版**安装成 PWA / 加到手机主屏幕**，它比普通书签更稳——手机主屏幕图标、电脑桌面图标，断网也能点读。

一句话：**轻用加书签，重装装 PWA。**

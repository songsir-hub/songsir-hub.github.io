## 前提：要有稳定的 GitHub 访问环境

本文所有操作都依赖 GitHub。动手前请先确认两件事：

- 你能**稳定访问 GitHub**（网络通畅，或已配好代理 / 镜像通道）；
- 已在本机安装 `gh` 并完成登录（`gh auth login`，走浏览器或设备码）。

环境不稳，下面的同步就会时灵时不灵。先把地基打牢，再谈协同。

![多台设备通过发光的数据流同步到云端配置仓库](/images/workbuddy-sync-cover.png)

## 一、为什么：配置不该只活在一台机器上

WorkBuddy 的"本领"大多是文件，默认只躺在当前机器的 `~/.workbuddy` 里：

- **技能（`skills/`）**：你沉淀的可复用工作流；
- **记忆（`MEMORY.md` / `memory/`）**：跨会话记住的偏好与约定；
- **任务库（`tasks/`、`workbuddy.db`）**：历史上下文。

换电脑、重装、磁盘损坏，这些东西就归零。而 WorkBuddy 启动时会自动扫描 `skills/`、读取记忆文件——所以"用 GitHub 托管配置"，本质就是让任意一台机器都能一键拿到这份目录，**便捷**地延续你的工作习惯。

## 二、怎么做：私有配置仓库 + 两个脚本

准备一个**你自己的私有 Git 仓库**（下文统称"配置仓库"），用两个脚本管理：

- **推送端** `workbuddy-sync.py`：把本机配置增量同步到仓库；
- **抓回端** `workbuddy-restore.py`：把仓库配置一键拉回本机。

新电脑想获得你的技能与记忆，只需四步：

1. 克隆（或先取一次抓回脚本）你的私有配置仓库；
2. 配置鉴权——推荐 `gh` 登录态，或设一个环境变量令牌；
3. 运行抓回脚本，它会把技能、记忆、任务库**全部拉回**，覆盖前自动备份，不误删现有内容；
4. 重启 WorkBuddy，"新本领"即时生效。

以后在本机改了技能 / 记忆，一条命令增量同步回仓库，多机之间永远一致。**一次配置，处处可用。**

## 三、安全：用登录态读写 GitHub 库，告别明文密钥

很多人图省事，把令牌（token / PAT）直接写进配置文件，再随备份推上仓库——哪怕私有库，也等于把钥匙放在人人可翻的抽屉里，且 Git 历史极难彻底清除。

![明文密钥如同一把裸露的钥匙从裂缝中泄露，暗处有手伸来](/images/pat-plaintext-risk.png)

更好的做法是**根本不持有明文密钥**。`gh` 的登录态就是为此设计的：

- `gh auth login` 走浏览器 / 设备码，令牌存进系统钥匙串，**不落文件、不进记忆**；
- 脚本需要时调 `gh auth token` 现取现用，用完即弃；
- 想作废？`gh auth logout` 或到 GitHub 后台撤权即可，**没有明文可泄露**。

![通过浏览器设备码登录，令牌被盾牌包裹、始终不以明文出现](/images/gh-token-secure.png)

把同步脚本的鉴权改成优先登录态后，本机彻底告别明文密钥；其他仍用传统令牌的机器，脚本也保留兼容兜底。

> 经验之谈：曾有人把各类密钥明文写进配置文件、还随备份上传，存在不小泄露风险。处理办法只有三条——到后台撤销对应令牌、轮换仍有效的密钥、**不要再写明文**。涉及具体仓库名、密钥值等敏感信息，对外分享时务必模糊处理。

## 四、效果：多机协同，一台改处处新

![三台不同形态的设备把配置同步到中央仓库立方体](/images/multi-machine-arch.png)

把配置放进"配置仓库"后，协同就变成一件轻松的事：

- 在公司电脑调好的技能，回家用笔记本抓回即用；
- 重装系统后，半小时就能还原整套工作流；
- 多台机器之间，永远以仓库里的最新版为准。

便捷来自"即插即用"，安全来自"无明文"——两者并不冲突。

## 五、迁移：换电脑前记住这几条

- ✅ **云端无忧**：博客、书稿、配置备份都在 GitHub，换电脑直接克隆；
- ⚠️ **本机工具要重装**：`gh` CLI；若用捆绑的 Git，记得把凭据助手指向 `gh`，否则推送会卡在弹窗；
- ⚠️ **项目记忆随工作目录走**：当前工作区的记忆不在同步范围内，换电脑要连同整个工作目录一起迁移；
- 🔑 **登录态要重做**：旧机器钥匙串里的令牌不会跟你走，新机器 `gh auth login` 一次即可。

## 结语

把 `~/.workbuddy` 当作"可版本化的资产"，配合"登录态替代明文密钥"，你既拿到了多机协同的**便捷**，又守住了**安全**的底线。对外分享时，记住一条铁律：**能模糊的敏感信息，一律模糊**。下次换电脑，别再从头调教——抓回备份，继续干。
